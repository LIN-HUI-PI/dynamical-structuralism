系統架構

LIN System 分成哪幾層。每一格連到對應的部門頁。

根

理論起點，其他一切由它而來。

  • 動力結構主義 Dynamical Structuralism

規範閘門

不是功能層，是所有操作的進入條件。

  • RGP 規範基底協議成員資格待定

核心治理層

四個依序銜接的模組：決定 → 身分 → 執行 → 凍結與恢復。

  • Decision Mirror 決策鏡
  • NOIRÉA
  • HAEB
  • HÚPLŃ稽核中

橫切軸

不是一層，而是穿過所有層的語意軸。

  • 失效語義層 Failure Semantics Layer

地板

整套系統站在其上的物理前提。

  • 物理基底層 Physical Ground Layer稽核中

介面延伸

與核心有真實的數學連結，但不屬於核心治理層。

  • ESM 具身狀態機
  • Bionic Node 仿生節點
  • IMLAIS
  • Spinal-Shield (Ø)

側向框架

與主體並行發展的獨立工作。

  • DSCI
  • PIM

  • TOM

  • Sentinel
  • Reachable Geometry
  • Constellarium
