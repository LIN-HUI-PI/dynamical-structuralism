治理架構。核心為四個治理層，加上貫穿各層的 Failure Semantics Layer；ESM、Bionic Node 與 IMLAIS 屬於延伸介面，不是核心層。

核心層

  • Layer 0Decision Mirror
  • Layer 1NOIRÉA
  • Layer 2HAEB
  • Layer 4HÚPLŃ
  • 貫穿Failure Semantics Layer：LCS → OTL → SPI → ECI

延伸：ESM（Layer 3）、Bionic Node、IMLAIS。
