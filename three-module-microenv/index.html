Retina → Entorhinal → Spinal

micro-environment v3：三個 bistable module 串聯，檢驗 hidden damage 是否沿鏈傳遞，以及下游 hidden metric 能否預測 cascade。

Model

  • 每個 module：dxi/dt = ai + (1−Di)xi − xi³ + σξ；phenotype = 1[xi<0]。
  • Insult：只對 Retina 施加 repeated subthreshold pulse（振幅 A），每次累積 δ。
  • Hidden damage transmission：DEC += κ·δ，DSC += κ²·δ。
  • Coupling：aEC = c·(1−sRet)，aSC = c·(1−sEC)，s = sigmoid(−5x)。上游 flip 才對下游施加 drive c。
  • Hidden metric：每個 module 的 return time τ。
